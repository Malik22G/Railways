# 🚂 The Kingdom's Railway Network

**The Kingdom's Railway Network** is an interactive web-based puzzle game developed for the Web Programming course at Eötvös Loránd University (ELTE). Players are tasked with designing a continuous circular railway that traverses every accessible part of the kingdom, navigating various terrains and obstacles.

---

## 📜 Game Overview

In the realm of Seeknotland, King No-Name aspires to construct a circular railway connecting all corners of his kingdom. Entrusted with this mission, the royal advisor, Trickles, faces challenges posed by diverse terrains. Players assist Trickles by:

- **Building Tracks:** Lay down railway tracks on a square grid map.
- **Navigating Terrains:** Adapt to different tiles such as empty lands, bridges, mountains, and oases, each influencing track placement uniquely.
- **Strategizing Routes:** Ensure the railway forms a non-intersecting loop, covering all required tiles without revisiting any.
